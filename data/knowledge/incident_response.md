# 事件响应 SOP

本 Demo 支持 ERP、VPN 和报表数据库的故障登记。须明确一个资源和具体症状或报错。
access denied、403 等错误本身属于故障证据，不等于申请开通权限。
对于“没有权限、access denied、403，帮我处理”而没有使用历史的描述，先询问之前是否正常使用。
上述使用历史问题仅适用于权限类报错。连接超时、服务 503、宕机等已有明确故障症状时可直接登记，不必额外询问是否首次使用。
以前正常、突然失败：登记故障，不推测为首次授权。第一次使用且明确请求开通：转权限申请 SOP，并收集权限范围。
“故障还是申请”是同一诉求的候选解释，不应直接当作两个独立诉求。
同一描述还包含权限申请等其他诉求时先澄清本单处理哪个诉求，不能静默丢弃另一个。
严重程度沿用提交字段，仅用于登记。当前不执行值班通知、诊断修复或故障恢复操作。
closed 表示 Agent 的登记任务完成；外部故障是否解决仍未知，不能宣称已经修复。
