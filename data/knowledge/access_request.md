# 权限申请 SOP

本 Demo 只处理本人对 ERP/VPN 的普通使用权限、报表数据库的只读权限。
申请人身份来自后端认证；必须明确一个资源和权限范围。缺失时先澄清，不推测默认权限。
仅报告 403 或没有权限时，不能直接认定为权限申请：须先区分已有访问故障与首次申请。
第一次使用且明确表示需要开通时，可提出权限计划；此前能用现在异常时，应走事件响应 SOP。
模型推断出的权限计划须经本人确认；所有权限计划均需本部门经理或管理员独立审批，禁止自审。
审批绑定具体账号、资源、权限和严重程度；更改计划不能沿用原审批。
管理员、读写、第三方账号及目录外权限转人工。本 Demo 不实现生产授权的用途/有效期管理。
模拟开通成功只表示 Agent 任务完成，不表示真实 IAM 已授权。
